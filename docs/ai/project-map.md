# خريطة مشروع OZK TOBACCO

## البنية

| الطبقة | المسؤولية | المسارات الأساسية |
|---|---|---|
| واجهة PWA | الإدارة، المبيعات، النشرات، التقارير | `index.html`, `src/`, `public/` |
| Supabase | المصادقة، الجداول، RLS، Edge Functions | `supabase/` |
| تكامل Windows | قراءة/مزامنة الأمين والمهام المجدولة | `tools/` |
| التوليد والفحص | النشرات وPDF واختبارات العقود | `scripts/` |
| النشر | GitHub Pages وتوليد النشرات | `.github/workflows/` |
| تنسيق العمل | القفل والتسليم والمعرفة الموضوعية | `AI_*`, `docs/ai/` |

## مصادر الحقيقة للبيانات

| البيانات | المصدر الموثوق | الاتجاه الطبيعي |
|---|---|---|
| المحاسبة، الفواتير، الحركات، الأرصدة، المخزون | الأمين `AmnDb002` | الأمين → Supabase/الموقع |
| الأسعار المعتمدة | Supabase `approved_price_items` | Supabase → الأمين والنشرات |
| سعر صرف النشرة السورية | `scripts/exchange-rate.json` بعد الاعتماد | الموقع/workflow → التوليد |
| الملفات المنشورة للزبائن | مولدات المستودع وGitHub Pages | بيانات الأسعار → `public/downloads/` |

## حدود لا تُخلط

- الموقع تطبيق ثابت HTML/JavaScript/CSS؛ لا React ولا Vite من دون قرار صريح.
- Supabase ليس المصدر المحاسبي البديل عن الأمين.
- تقارير Windows والنسخ الاحتياطية والبيانات الخاصة لا تُنشر على الاستضافة العامة.
- القفل في `AI_ACTIVE_TASK.json` يحدد ملكية الملفات الجارية؛ تقارير المواضيع تلخص الحالة، ولا تستبدل القفل أو سجل التسليم.
