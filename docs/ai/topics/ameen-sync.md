# تقرير موضوع مزامنة الأمين

آخر تحديث: 2026-08-23

## الحالة الحالية

توجد مهام Windows منفصلة للأسعار والمخزون والأرصدة والفواتير والحركات والتكاليف. قاعدة التشغيل المعتمدة هي `AmnDb002`. لا يثبت هذا التقرير أن كل مهمة تعمل الآن؛ يلزم دليل حديث لكل مسار عند تشخيصه.

## المصدر الموثوق

الأمين للبيانات المحاسبية، وSupabase للأسعار المعتمدة. اتجاه البيانات مفصل في `docs/ai/project-map.md` ولا يجوز عكسه عرضاً لإخفاء فشل مزامنة.

## نطاق الملفات

`tools/ameen-sync-agent.ps1`, `tools/ameen-read-*.ps1`, `tools/pull-*.ps1`, `tools/push-*.ps1`, `tools/register-*.ps1`, `tools/verify-*.ps1`, `supabase/ameen-*.sql`.

## قيود ثابتة

- `AmnDb001` تاريخية وليست قاعدة التشغيل.
- نجاح Scheduled Task أو process وحده ليس دليلاً؛ يلزم أثر العملية المحددة وحداثته.
- الأسرار تبقى خارج Git ولا تُطبع أو تُنسخ إلى التقارير.
- الكتابات إلى الأمين تحتاج صلاحية صريحة ومقارنة قبل/بعد مناسبة للمخاطر.

## فحوص إلزامية

فحص parser المناسب لـPowerShell 5.1، `npm.cmd run check` للعقود المرتبطة، حالة المهمة/العملية، ثم دليل مستقل خاص بالبيانات التي كان يجب سحبها أو دفعها.

## الخطوة التالية

عند إصلاح أي مسار، سجّل اسم المهمة المنطقية ووقت آخر نجاح ودليل النتيجة من دون connection strings أو مفاتيح.
