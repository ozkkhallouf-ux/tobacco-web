## ترتيب مصادر الحقيقة

عند وجود اختلاف، اتبع هذا الترتيب:

1. الحالة الحية المثبتة والكود الحالي على `main`.
2. `AI_ACTIVE_TASK.json` لمعرفة العمل الجاري والملفات المحجوزة.
3. تقرير الموضوع المناسب في `topics/`.
4. `AI_HANDOFF.md` للتاريخ التفصيلي للمهام المنتهية.
5. ذاكرة المحادثة القديمة، وتُعامل كدليل يحتاج تحققاً وليست حقيقة حية.
