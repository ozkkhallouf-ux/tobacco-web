# قالب بدء مهمة OZK

المصدر الرسمي لقالب `#تطوير-ozk`. الأقسام **نص داخل المستند الرئيسي**، وليست روابط أو بطاقات ملفات.

## لماذا هذا الشكل

في Canvas سلاك، إدراج مستند كرابط/بطاقة يمنع حذف نصه أو تعديله داخل المستند الرئيسي. النسخ من رابط ينقل الرابط لا المحتوى. لذلك:

1. المستند الرئيسي `main.md` يحمل كل الأقسام كنص جاهز للحذف والإضافة.
2. كل قسم له ملف مستقل تحت `addons/` يُنسخ عند الحاجة ويُلصق كنص في المستند الرئيسي أو في ثريد المهمة.

لا تُدرَج ملفات GitHub ولا Canvas أخرى كبطاقات داخل القالب.

## طريقتان للبدء

### 1) المستند الرئيسي ثم الحذف

انسخ محتوى `main.md` كاملاً إلى Canvas أو رسالة القناة. املأ «بيانات المهمة». احذف أي قسم لا تحتاجه هذه المهمة.

### 2) ملفات تُضاف في كل مرة

ابدأ بـ `addons/task-data.md` فقط. إن احتجت سير العمل أو القواعد أو تقرير القرار، انسخ الملف المقابل من `addons/` والصقه كنص — لا تلصق رابطه.
