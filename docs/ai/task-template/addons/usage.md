## طريقة الاستخدام

انسخ قسم **بيانات المهمة** عند بدء أي مشكلة جديدة في قناة تطوير OZK، املأ المشكلة والهدف، ثم وجّه المهمة إلى الوكيل داخل الثريد وفق سير العمل أعلاه.

الأقسام الأخرى نص داخل هذا المستند: احذف ما لا تحتاجه، وأضف قسماً بنسخ ملفه من `docs/ai/task-template/addons/` ولصقه هنا كنص. لا تدرج روابط ملفات أو بطاقات Canvas بدل النص.
