# OZK - طباعة فواتير A4 (يدوياً عند الطلب)

أداة على Windows تطبع فاتورة جملة واحدة على Canon G3410 حين يطلبها المستخدم، بدل
الطباعة التلقائية لكل فاتورة. الهدف تقليل استهلاك الورق والحبر.

## كيف تعمل

1. اختصار سطح المكتب «OZK - طباعة فواتير A4» يشغّل `launch.ps1`.
2. `launch.ps1` يشغّل خادماً محلياً (`server.js`) على `127.0.0.1:47616`، ثم يفتح الواجهة
   في نافذة Edge مستقلة.
3. المستخدم يُدخل رقم الفاتورة، فيبحث الخادم في AmnDb002 قراءةً فقط. إن تكرر الرقم بين
   أنواع الفواتير تُعرض كل السجلات بالنوع والتاريخ والزبون والإجمالي، ليختار المستخدم.
4. المعاينة PDF بالقالب الرسمي نفسه (`tools/ameen-autoprint/invoice-html.js`) وخط Cairo
   مضمَّناً. إن لم يُضمَّن الخط تُمنع الطباعة.
5. زر «طباعة» مع عدد النسخ (الافتراضي 1). الإرسال يتم عبر SumatraPDF إلى الطابعة
   المسمّاة، ولا يسقط أبداً إلى الطابعة الافتراضية.

## الحدود

- **قراءة فقط:** كل استعلام يمرّ بحارس `lib/sql-guard.js`، الذي يرفض أي نص ليس `SELECT`
  صافياً قبل إرساله. ويُفضَّل حساب `ozk_print_reader` (`db_datareader` فقط)، ولا يُقبل `sa`.
- **أنواع الفواتير:** تُطبع أنواع الجملة المعتمدة وحدها. «مبيعات المركز» (الكاشير 80mm)
  محجوبة دائماً.
- **لا مساس بالتلقائي:** الأداة لا تكتب على ملف حالة المراقب ولا تلمس مهمته. على
  OZK2026 تقرأ ملف حالته لتنبّه أن الفاتورة «طُبعت تلقائياً».
- **السجل محلي:** `%LOCALAPPDATA%\OZK\ManualA4Print\print-log.jsonl`، بصيغة سطر لكل
  حدث (search، preview، print_requested، print_sent، print_failed، print_rejected،
  dry_run).
- **فحص الطابعة قبل الإرسال:** تُرفض الطباعة إن كانت الطابعة Offline أو فيها خطأ (ورق، حبر، غطاء، انحشار) أو لا تردّ على الشبكة، كي لا تبقى الفاتورة في الطابور وتخرج لاحقاً فوق طبعة أخرى. وجود مهام سابقة عالقة في الطابور يظهر تنبيهاً.
- **مستقلة عن الموقع:** تعمل حتى لو كان الموقع أو Supabase متوقفاً. تحتاج فقط SQL
  الأمين على الشبكة المحلية والطابعة.

## منع التكرار

- لا طباعة بلا معاينة. كل معاينة لها رمز، والضغط المزدوج يحمل الرمز نفسه.
- طلبان متزامنان لفاتورة واحدة يعني أن الثاني يُرفض («قيد الإرسال»).
- خلال 10 ثوانٍ من إرسال ناجح يُرفض أي إرسال آخر للفاتورة نفسها.
- إذا طُبعت الفاتورة سابقاً على هذا الجهاز، فلا إعادة إلا بتأكيد صريح في نافذة تعرض
  الطبعات السابقة.
- **حدّ معروف:** السجل لكل جهاز على حدة، فطبعة على OZKUSER لا تظهر على OZK2026.

## الإعداد (`config.json` بجانب `server.js`)

| المفتاح | الافتراضي | المعنى |
|---|---|---|
| `dryRun` | `true` | لا يُرسل شيء للطابعة، ويُسجَّل الحدث فقط. يُطفأ بعد موافقة المالك على اختبار ورقي |
| `printerName` | `Canon G3410 WiFi` | الاسم كما في Windows |
| `printerHost` | `""` | عنوان الطابعة لفحص ردّها قبل الإرسال. منفذ TCP/IP يُقرأ عنوانه آلياً. طابور IPP Class Driver يُفحص على الرابط المحفوظ لعقدة `SWD\IPP\<UUID>`. طابور WSD يُسأل عنه بمعرّفه (UUID) عبر WS-Discovery ويُفحص العنوان الذي تردّ به الطابعة الآن، فتغيّر عنوان DHCP لا يرفض الطباعة. القيمة هنا تتقدّم على كل ذلك |
| `printerHostPort` | `631` | منفذ الفحص مع `printerHost` |
| `papers` | `["A4"]` | `["A4","A5"]` لتفعيل A5. هو نفس القالب مصغّراً، ويحتاج ورق A5 في الدرج |
| `maxCopies` | `5` | أقصى عدد نسخ |
| `autoPrintStatePath` | `""` | على OZK2026: مسار `last-printed.json` للمراقب (قراءة فقط) |
| `autoPrintTaskName` | `""` | على OZK2026: `OZK-AmeenAutoPrint`، لعرض حالته في الواجهة |

## التثبيت

1. ابنِ الحزمة على الـMac:
   ```
   node scripts/build-manual-a4-print-bundle.mjs --out <dir> --node-exe <node.exe> --sumatra <SumatraPDF.exe>
   ```
2. انسخها إلى `C:\ProgramData\OZK\ManualA4Print\app\`.
3. احفظ سرّ الاتصال بحساب القراءة (من stdin، ولا يُطبع):
   ```
   set-sql-secret.ps1 -User <user>
   ```
4. أنشئ `config.json` من `config.example.json`.
5. أنشئ الاختصار:
   ```
   install.ps1 -DesktopUser <user>
   ```
6. اختبر بلا ورق:
   ```
   node server.js --health
   node server.js --selftest <رقم>
   ```

## التحويل من التلقائي إلى اليدوي (OZK2026 فقط، بموافقة المالك)

```
autoprint-mode.ps1 -Status                    # قراءة فقط
autoprint-mode.ps1 -Disable                   # يوقف OZK-AmeenAutoPrint ويعطّلها بعد نسخ XML
autoprint-mode.ps1 -Restore -SkipBacklog      # يعيد الوضع القديم بلا طباعة المتراكم (الموصى به)
autoprint-mode.ps1 -Restore -AcceptBacklog    # يعيد الوضع القديم ويطبع المتراكم
```

**تنبيه الاسترجاع:** المراقب يلحق بكل فاتورة جملة لم يطبعها خلال آخر 7 أيام. فبلا
`-SkipBacklog` ستُطبع دفعة واحدة كل فاتورة صدرت أثناء التعطيل، بما فيها ما طُبع يدوياً.
`-SkipBacklog` ينسخ `last-printed.json` احتياطياً، ثم يعلّمه `schemaVersion = 1` فيشغّل
المراقب دورة الترحيل الموجودة فيه: يتبنّى ما في النافذة بلا ورق ويسرد أرقامه في
`autoprint.log`. قبل الاعتماد عليه تحقّق أن `watcher.js` المنشور على الجهاز يحوي
`adoptBaseline`.

## الإزالة الكاملة

- `install.ps1 -DesktopUser <user> -Remove` يزيل الاختصار.
- احذف `C:\ProgramData\OZK\ManualA4Print\`.
- لا شيء آخر تغيّر على الجهاز.
