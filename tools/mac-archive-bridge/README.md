# OZK Automatic iCloud Archive — الجسر المحلي (macOS)

حفظ تلقائي لنسخة PDF من كل مستند يُصدَّر من موقع OZK داخل مجلد iCloud Drive
المناسب على جهاز الماك، باسم عربي واضح، بلا اختيار مكان الحفظ يدوياً.

> **ميزة اختيارية على الماك فقط.** بيئة التشغيل والمزامنة الرسمية للمشروع تبقى
> Windows (جهاز LOQ). إن كان الجسر مطفأ أو غير مثبّت، يتصرّف الموقع كما كان
> تماماً: تنزيل/طباعة عادية بلا أي فرق ولا أي خطأ.

---

## التثبيت

```bash
npm run archive:install
```

يُنشئ `~/Library/LaunchAgents/com.ozk.archive-bridge.plist` ويشغّل الخدمة فوراً.
تعمل تلقائياً عند كل تسجيل دخول لمستخدم الماك وتعود بعد إعادة التشغيل، وتُعاد
تلقائياً إن انهارت (`KeepAlive`).

التحقق:

```bash
curl -s -H 'Origin: https://ozktobacco.com' http://127.0.0.1:8787/health
```

الإزالة: `npm run archive:uninstall` — لا تُمسّ الملفات المؤرشفة ولا السجلات.

## أين تعيش الأشياء

| المكوّن | المسار |
|---|---|
| الكود (مصدر واحد، داخل Git) | `tools/mac-archive-bridge/` |
| الإعدادات | `~/OZK-Archive-Bridge/config.json` |
| رمز المصادقة (0600، خارج Git) | `~/OZK-Archive-Bridge/token` |
| السجلات | `~/OZK-Archive-Bridge/logs/` |
| عميل الواجهة | `src/icloud-archive.js` |
| الفحوص | `scripts/check-mac-archive-bridge.mjs` (ضمن `npm run check`) |

> **مجلد عمل الخدمة خارج `~/Documents` عمداً.** قياس فعلي (2026-08-31): تعيين
> `WorkingDirectory` لـLaunchAgent داخل `~/Documents` يجمّد Node عند `getcwd`
> فلا يصل إلى الاستماع إطلاقاً. قراءة ملفات المستودع نفسها تعمل بلا مشكلة.

### اكتشاف المجلدات

لا مسار ثابت. الجسر يقرأ جذر iCloud Drive ويطابق الأسماء بعد تطبيع Unicode
(NFC + حذف محارف الاتجاه غير المرئية + توحيد الهمزات والتاء المربوطة). هذا
ضروري فعلياً على هذا الجهاز:

- `فواتير الزبائن` مخزَّن **NFD** (الهمزة محرف مركّب منفصل)
- `نشرات أسعار` مخزَّن **NFD**
- `فواتير المشتريات` يبدأ بمحرف **U+200F (RLM)** مخفي بصرياً

الكتابة تستعمل دائماً الاسم الحقيقي كما هو على القرص. الجسر **لا ينشئ مجلدات**؛
المجلد المفقود يرجع خطأ 409 واضحاً.

## واجهة HTTP

كلها على `127.0.0.1` فقط.

| المسار | الوصف |
|---|---|
| `GET /health` | حالة الجسر + جاهزية iCloud + المجلدات الناقصة (بلا رمز) |
| `GET /pair` | يعطي الرمز للأصل المسموح فقط (يمكن إيقافه من `config.json`) |
| `POST /archive` | يحفظ المستند (يتطلب `X-OZK-Archive-Token`) |

جسم `POST /archive`:

```jsonc
{
  "docType": "invoice",
  "meta": { "party": "حسن عباس", "number": "562", "date": "2026-08-31" },
  "baseUrl": "https://ozktobacco.com/",   // اختياري، لحلّ الشعار فقط
  "html": "<div class=\"ozk-rpt\">…</div>" // أو "pdfBase64": "…" — واحد منهما فقط
}
```

- **`html`**: يحوّله الجسر بـChromium (نفس محرك نافذة الطباعة) فيخرج نص عربي
  متجه قابل للبحث. هذا المسار الافتراضي لأن سطح المكتب في الموقع يطبع أصلاً
  ولا ينتج Blob.
- **`pdfBase64`**: يُستعمل حين يملك الموقع الملف فعلاً (فاتورة المبيعات مثلاً)
  فتصير النسخة المؤرشفة مطابقة حرفياً لما استلمه الزبون.

الرد: `{ ok, status: "saved" | "duplicate", folder, file }`. المسار المطلق لا
يُعاد للواجهة إطلاقاً.

## الأمان

| الطبقة | ماذا تمنع |
|---|---|
| استماع على `127.0.0.1` فقط | أي وصول من الشبكة |
| قائمة أصول مسموحة + CORS | أي صفحة ويب أخرى (تفشل في preflight) |
| فحص ترويسة `Host` | إعادة ربط DNS (نطاق مهاجم يشير إلى 127.0.0.1) |
| رمز عشوائي 256-bit، مقارنة ثابتة الزمن | أي عملية محلية غير المتصفح |
| `docType` من خريطة مغلقة | كتابة خارج المجلدات التسعة |
| الموقع لا يرسل مساراً ولا اسم ملف | حقن مسار / path traversal |
| تنقية أجزاء الاسم + فحص `path.dirname` | الخروج عن المجلد الهدف |
| `writeFile` بعلم `wx` | استبدال أي ملف موجود |
| حصر شبكة Chromium بأصل الموقع | استغلال الجسر كأداة جلب روابط |
| حدّ حجم + حدّ معدّل | إغراق القرص أو الخدمة |

- الرمز **ليس** داخل الكود ولا داخل المستودع. الصفحة تسحبه مرة واحدة من `/pair`
  وتحفظه في `localStorage` الخاص بهذا المتصفح.
- خط الدفاع الأول هو قائمة الأصول؛ الرمز طبقة إضافية ضد العمليات المحلية.
  لإلغاء الربط التلقائي: اضبط `"autoPair": false` ثم الصق محتوى ملف `token`
  في `localStorage` تحت المفتاح `ozk.archive.token`.
- الجسر **لا يقترب** من قاعدة الأمين ولا من Supabase ولا من أي بيانات محاسبية.
  ملفات PDF فقط.

## توافق المتصفحات (مقيس، 2026-08-31)

| كيف تفتح الموقع | Chrome / Edge | ملاحظة |
|---|---|---|
| `http://localhost:5173` (الخادم المحلي) | ✅ يعمل مباشرة | لا إذن ولا تنبيه |
| `https://ozktobacco.com` | ✅ بعد السماح مرة واحدة | المتصفح يطلب إذن «الوصول إلى الشبكة المحلية» |

قياس فعلي: الطلب نفسه من صفحة https فشل بلا إذن (`Permission was denied for this
request`) ونجح بـ`200` فور منحه.

**Safari و`OZK.app`:** بناء WebKit في Playwright حجب الطلب في الحالتين. هذا ليس
Safari حرفياً فيبقى التحقق النهائي مطلوباً على Safari الفعلي؛ حتى ذلك الحين
التوصية على الماك هي Chrome، أو فتح الموقع من الخادم المحلي.

إن فشلت الأرشفة على https تظهر رسالة تذكر الإذن صراحةً — لا تطارد عطلاً في
الجسر قبل التأكد من الإذن (`curl` على `/health` يكشف حالة الجسر فوراً).

## التحكّم من المتصفح

```js
window.ozkArchive.disable();  // إيقاف الأرشفة على هذا المتصفح
window.ozkArchive.enable();   // إعادة تشغيلها
window.ozkArchive.reset();    // نسيان الرمز وإعادة الربط
await window.ozkArchive.probe(true); // فحص التوفّر الآن
```
